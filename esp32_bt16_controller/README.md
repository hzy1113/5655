# ESP32C3 触摸磁吸充电蓝牙功放控制器

## 项目概述

使用ESP32C3作为主控，通过TTP223触摸模块检测磁铁靠近，实现对大吴BT-16蓝牙功放板的控制。

## 功能特性

- **自锁功能**：快速按两下解锁/上锁
- **低功耗**：锁屏时ESP32进入深度睡眠
- **触摸控制**：
  - 单次触摸：暂停/播放
  - 两次触摸：下一首
  - 长按（>1s）：音量+
  - 长按（>2s）：开关机

## 硬件接线

```
ESP32C3          TTP223模块(1)   TTP223模块(2)   BT-16功放
----------       ------------   -------------   --------
GPIO4  <-------- TP1 (SIG)      TP2 (SIG)       (触摸控制)
GPIO5  <-------- TP1 (SIG)      TP2 (SIG)
GPIO6  <------------------------ TP2 (SIG)
GPIO7  <-------- TP1 (SIG)
GPIO8  <-------- TP1 (SIG)
GPIO10 <-------- TP1 (SIG)

GPIO0  -----------------------------------------> PLAY/PAUSE (功放控制)
GPIO1  -----------------------------------------> NEXT (功放控制)
GPIO2  -----------------------------------------> VOL+ (功放控制)
GPIO3  -----------------------------------------> VOL- (功放控制)
GPIO21 -----------------------------------------> POWER (功放控制)

3.3V  --------------- VCC              VCC
GND   --------------- GND              GND
```

## 功耗说明

- **工作状态**：约30-50mA
- **深度睡眠**：约10-15uA（需外接 RTC PMU，如AXP2101）

## 快速开始

1. 安装PlatformIO
2. 克隆项目后执行 `pio run`
3. 上传固件 `pio run -t upload`

## 触摸协议

| 触摸次数 | 动作 |
|---------|------|
| 1次     | 暂停/播放 |
| 2次     | 下一首 |
| 3次     | 音量+ |
| 长按2s  | 开关机 |
| 长按3s  | 锁屏/解锁 |
