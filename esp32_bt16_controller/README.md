# ESP32C3 触摸蓝牙功放控制器

使用ESP32C3 + 2个TTP223触摸模块 控制大吴BT-16蓝牙功放板。

## 硬件

- ESP32-C3-MINI
- TTP223触摸模块 x2
- 大吴BT-16蓝牙功放板
- 磁吸充电模块

## 接线

```
ESP32-C3    TTP223      BT-16
--------    ------      -----
GPIO4  ◄─── 模块1
GPIO5  ◄─── 模块2
GPIO0  ────         ► 按钮1
GPIO1  ────         ► 按钮2
3.3V   ──── VCC
GND    ──── GND     GND
```

## 触摸协议

| 模块 | 动作 | 功能 |
|------|------|------|
| **模块1** | 单击 | 播放/暂停 |
| **模块1** | 双击 | 下一首 |
| **模块1** | 长按1秒 | 下一首 |
| **模块1** | 长按2秒 | 锁屏 |
| **模块2** | 单击 | 音量+ |
| **模块2** | 长按1秒 | 音量- |
| **模块2** | 长按2秒 | 锁屏 |
| **锁屏** | 双击模块1 | 解锁 |

## 开发

```bash
pio run          # 编译
pio run -t upload  # 上传
pio device monitor  # 串口
```
