# ESP32C3 触摸蓝牙功放控制器 - 硬件文档

## 硬件接线

```
                    ┌─────────────────────┐
                    │    ESP32-C3-MINI    │
                    │                     │
GPIO4 ◄──────────────┤ TP1 (触摸模块1)     │
GPIO5 ◄──────────────┤ TP2 (触摸模块2)     │
                    │                     │
GPIO0 ──────────────► AMP_PLAY_PAUSE      │
GPIO1 ──────────────► AMP_NEXT            │
GPIO2 ──────────────► AMP_VOL_UP          │
GPIO3 ──────────────► AMP_VOL_DOWN        │
GPIO21 ─────────────► AMP_POWER           │
                    │                     │
3.3V ───────────────► VCC (所有模块)      │
GND  ───────────────► GND                 │
                    └─────────────────────┘
```

## 触摸协议

| 触摸模块 | 动作 | 功能 |
|---------|------|------|
| **模块1** | 单击 | 暂停/播放 |
| **模块1** | 双击 | 下一首 |
| **模块1** | 三击 | 锁屏 |
| **模块1** | 长按1秒 | 音量+ |
| **模块1** | 长按3秒 | 锁屏 |
| **模块2** | 单击 | 暂停/播放 |
| **模块2** | 双击 | 下一首 |
| **模块2** | 长按1秒 | 音量- |
| **模块2** | 长按2秒 | 开关机 |

## 锁屏状态

- **锁屏时**：只有模块1可用于解锁（快速按两下或长按3秒）
- **解锁后**：所有功能恢复

## 功耗

| 状态 | 电流 | 说明 |
|------|------|------|
| 工作 | ~40mA | 正常播放 |
| 深度睡眠 | ~10μA | 锁屏模式 |

## 完整接线表

| ESP32-C3 | TTP223模块 | BT-16功放 |
|----------|-----------|-----------|
| GPIO4 | TP1 (SIG) | - |
| GPIO5 | TP2 (SIG) | - |
| GPIO0 | - | PLAY_PAUSE |
| GPIO1 | - | NEXT |
| GPIO2 | - | VOL_UP |
| GPIO3 | - | VOL_DOWN |
| GPIO21 | - | POWER |
| 3.3V | VCC | - |
| GND | GND | GND |

## 时间参数

| 参数 | 值 | 说明 |
|------|-----|------|
| TAP_TIMEOUT | 400ms | 双击判定间隔 |
| LONG_PRESS_1 | 1秒 | 音量调节 |
| LONG_PRESS_2 | 2秒 | 开关机 |
| LONG_PRESS_3 | 3秒 | 锁屏/解锁 |
