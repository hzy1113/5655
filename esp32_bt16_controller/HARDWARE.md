# 硬件接线

```
        ┌─────────────────────────────────────────┐
        │           ESP32-C3-MINI                 │
        │                                         │
GPIO4 ◄─┼─── TTP223模块1 (播放控制)              │
GPIO5 ◄─┼─── TTP223模块2 (音量控制)              │
        │                                         │
GPIO0 ──┼────────────────────────► BT-16 按钮1    │
GPIO1 ──┼────────────────────────► BT-16 按钮2    │
        │                                         │
3.3V  ──┼─── VCC (所有模块)                     │
GND   ──┼─── GND (所有模块)                     │
        └─────────────────────────────────────────┘
```

## 完整接线表

| ESP32-C3 | TTP223模块 | BT-16功放 |
|----------|-----------|-----------|
| GPIO4 | 模块1 SIG | - |
| GPIO5 | 模块2 SIG | - |
| GPIO0 | - | 按钮1 |
| GPIO1 | - | 按钮2 |
| 3.3V | VCC | - |
| GND | GND | GND |

## 触摸功能

| 模块 | 动作 | BT-16功能 |
|------|------|----------|
| 模块1 | 单击 | 播放/暂停 |
| 模块1 | 双击 | 下一首 |
| 模块1 | 长按1秒 | 下一首 |
| 模块2 | 单击 | 音量+ |
| 模块2 | 长按1秒 | 音量- |
| 任意 | 长按2秒 | 锁屏 |
| 锁屏 | 双击模块1 | 解锁 |

## 时间参数

| 参数 | 值 |
|------|-----|
| 双击间隔 | 400ms |
| 长按1 | 1秒 |
| 长按2 | 2秒 |
